Yorikado 操作手順（事務局向け）
============================
ログイン: メール＋パスワード → 認証アプリの6桁コード（事務局は必須。8時間ごとに再ログイン）
画面上部: 組織名（メニュー: 精算・照合、設定、監査ログ、データ出力）と5つのタブ（対応待ち／地域券／依頼／相談／店舗）

対応待ち: 金額の例外（取消申請・精算の承認待ち・口座変更・発行）→ 紙券・回答確認 → 相談 → 未回答の依頼

地域券事業
  新しい事業（下書き）→ 公開を申請（担当）→ 承認して受付開始（別の承認者）
  QR券の発行: 発行（無効のまま）→「印刷データを開く」→ 印刷（PDF保存可）→ 実際に1枚スマホで読めるか確認
    →「枚数を確認した」→ 別の承認者が「有効化」。印刷データは24時間で取得不可（破棄して再発行）
  紛失・流出: バッチを「失効」、必要なら事業を「受付を停止」
  紙券: 申告一覧 → 原本確認（金額・原本の有無・保管場所。申告額と違う場合は理由）→ 確認済み／差戻し
  外部券: 実績CSVを「検査してプレビュー」→ エラー・差分・不明店を解消 → 確定（これは決済ではなく実績の記録）

精算・照合（組織メニュー → 精算・照合）
  集計して精算案 → 例外の解消 → 承認を依頼 → 承認者が承認 → 支払作業票（銀行取込用ではない）→ 銀行で振込
  → 銀行の結果CSVを取込 → 別の担当者が「照合結果を確定」→ 要確認の行は承認者が判断を記録
  再出力は「再出力」と明記されます。銀行で二重に振り込まないこと

依頼: 新しい依頼（テンプレート5種）→ 店舗の表示を確認 → 下書き保存 → 公開。訂正は「改版」。
  未回答の店へ「催促」（1店1日1回まで、09〜18時に届く）。電話や紙で聞いた回答は「代理入力」（理由必須）

相談: 担当者を割り当て → 店舗へ返信（店舗に表示）／内部メモ（店舗に表示されない）→ 完了（理由必須）

店舗: 登録・編集、担当者の招待・無効化、口座変更の承認（申請者と別の承認者・本人確認の方法を記録）
設定（管理者）: 連絡先・受付時間・メール通知、事務局メンバーの役割、データ出力
